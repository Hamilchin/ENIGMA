# Biralo

This is a game-jam entry for [js13kgames 2025](https://js13kgames.com/).
Theme: Black Cat

<img src="/screenshots/thumbnail.png">

**Description**:
Meow... Meow, Meow.... Meow, Meow Meow..
<br>
<br>

**Tools Used:**:
<br>GrafX2 - Arts and Animation,
<br>[spritesheet-viewer](https://github.com/smiley405/spritesheet-viewer) - for playing animation and exporting spritesheet,
<br>Ogmo-Editor-3 - level design,
<br>Neovim - Text Editor,

**How to test and run the game:**:
<br> 1. Clone this repository
<br> 2. Install packages: open the terminal and run: npm i
<br> 3. Run the game: open the terminal and run: npm run dev
<br> 4. To build the game: open the terminal and run: npm run build:max
<br> 5. The built game will be inside the /dist directory 
<br> 6. Requires installation of [advzip](https://github.com/amadvance/advancecomp) for the build command

**How to edit and export images:**:
<br>[Goto here](https://github.com/smiley405/biralo/tree/main/images/readme)
