Benchmark & RL environment · 2026

ENIGMA

Evaluating Novel Interactive Generality in Machine Agents

The idea

  • There is a large corpus of open-source games: js13kGames, an annual jam running since 2012 — every entry's source fits in 13 KB and is published on GitHub. Roughly 300 games across the past decade clear a quality bar for benchmarking.
  • Games are historically a good metric for intelligence — most recently shown by ARC-AGI-3, whose interactive game-like environments humans solve at 100% while frontier models score ~0.5%.
  • The sheer number and diversity of these games lets us test the generality of machine agents — no single game can be memorized or overfit.
  • Because the games are open source, we can add verifiable rewards — hook each game's code for exact, per-frame ground truth — and use the corpus as a benchmark (and RL environment) at the raw computer interface: screenshots in, mouse and keyboard out.

Precedents

  • ARC-AGI-3 — interactive game-like environments with no instructions or stated goals; humans 100%, frontier models ~0.5%. Purpose-built abstract worlds with a bespoke API, stripped of human context — ENIGMA is the complement: real games, real computer interface, human context required, real-time pressure. ARC Prize Foundation, 2026 (benchmark + competition)
  • VideoGameBench — 10 famous 1990s games, pixels-only, real-time vs paused "Lite" mode; best models complete 0.48%. Direct precedent for the two-clock design, but wall-clock timing and maximally contaminated games. arXiv preprint, 2025
  • lmgame-Bench — 6 games via a Gym-style API with a modular perception/memory/reasoning harness; source of the selective-memory scaffold ENIGMA uses. ICLR 2026
  • OSWorld — 369 real-desktop tasks with execution-based verification; the flagship computer-use benchmark, but sparse binary scoring and scripted productivity tasks. NeurIPS 2024, Datasets & Benchmarks

Notes

Computer use models must be generally intelligent, since computer use is such a general task. Any financially viable general intellgence must be a few things: First, it needs to be fast! Second, it needs to be competent. Third, it needs to generalize. Our benchmark is supposed to be very difficult, and measure the capacity of agents to universally adapt to new environments. A good measure of "general intelligence" is performance in new unseen games. Games are fun in part because they are difficult; they require real-time reasoning, they require critical thinking, etc etc etc. Games are also designed to be learnable: hard, but built to be figured out. Last but not least, they measure some form of abstract intelligence that is not well-captured in other domains, including language: the ability to learn how to adapt in-context to new visual environments. It's a great way to tell if a machine will think like a human does; whether it will pick up environmental cues, whether or not it can rapidly adapt like humans do. But to measure this we need a few things. First we need large task diversity. Ideally, we want games that the model has not seen before. Mastering atari or go is not a measure of "general intelligence." Second, we need an interface that is pretty general; for instance, the computer-use realm. Third, we need a way to verify game correctess! We need to know how well the players are doing Luckily, there are huge datasets of small games out there that test different skills. Unfortunately, it isn't super easy to use them as evaluation harnesses. Many of them are obscured, like flash games. But there are game jams where people spend a week or so making small games that are interesting and challenging in different ways! A huge amount of task diversity there. One is a notable open source game jam called js13k. Your source code has to fit within 13 kilobytes. All game source is also available on github. This means that not only can we do VLM rewards, we can do verifiable rewards by editing, inspecting, and adding hooks to the game code itself! Abstract

Computer-use agents are typically evaluated with sparse end-state checks or subjective VLM judges, on tasks whose solutions saturate their training corpora. We present ENIGMA (Evaluating Novel Interactive Generality in Machine Agents), a benchmark of 66 browser games — scaling to 300+ — from the annual js13kGames competition, played through a raw screenshots-in, mouse-and-keyboard-out interface. ENIGMA couples five properties: verifiable rewards — dense, per-frame progress read from each game's internal state, replacing VLM judgment and enabling reinforcement learning; a large, annually renewing corpus; niche game worlds with effectively no demonstration or video data in training corpora; ARC-style novelty posed through the human interface, demanding human context knowledge in place of explicit instructions; and a deterministic virtual clock whose token-time mode prices reasoning in game time at each model's measured throughput, making competence under real-time constraint a reproducible quantity. Episodes are hermetic and bit-reproducible, and humans play through the identical recorded interface, yielding directly comparable baselines. ENIGMA measures not just whether an agent can figure out a world it has never seen — but whether it can do so fast enough to afford.
